# Rules

Rules are short, broadly applicable constraints that agents should keep in mind across many tasks. They should stay generic and compact.

Use workflows for step-by-step processes and skills for specialized on-demand capability. Do not put private project context, ticket IDs, customer names, internal hostnames, or one-off commands in shared rules.
