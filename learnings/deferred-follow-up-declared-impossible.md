# Solution
- Never state a flat "I cannot work after the conversation ends". Say what you checked
  (declared and deferred tools, scheduling tools, connectors) and what you found.
- If no scheduler exists, report that as a finding of the check and give a concrete fallback
  (for example a reminder whose text carries the full scope).

# Why
Deferred tools are invisible until searched, so "I can't" needs evidence; the stated check
lets the user see the limit is real.
