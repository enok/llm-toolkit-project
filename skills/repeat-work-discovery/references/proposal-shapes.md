# Generic proposal shapes

Read this while drafting the top-5 list, to match what you found against shapes
that have worked before. Each shape is generic: swap in the pattern actually
found, and never copy names, employers, addresses or amounts from the user's
data into a proposal or a saved skill.

| Shape | Pattern that suggests it | What the skill does | Safety line |
|---|---|---|---|
| Rotation prep and handoff | Recurring on-call or duty shift on a calendar | Reads the rotation calendar and related recent threads, prints a shift-start brief and a fill-in-the-blank handoff note | Read-only; the note is a draft |
| Recruiter reply triage | Cold outreach about roles, mixed with mass alerts | Separates genuine outreach from job-alert digests and drafts a reply using the user's standard qualifying questions (remote work, timezone, currency, salary range, start date) | Draft only; the user sends |
| Daily inbox digest | Large inbox where a few messages need action | Summarises recent mail into "needs your attention" (people, deadlines, money, shifts) versus promotional noise | Never deletes or archives |
| Recurring bill or accounting tracker | Monthly email with payment documents and due dates | Extracts amounts and due dates from the attachments, logs them to a running sheet, adds a calendar reminder before each deadline | Asks before writing the sheet or calendar; no account numbers in the skill |
| Tomorrow brief | Nightly planning habit | Lists tomorrow's events across all calendars plus threads still waiting for a reply | Read-only |
| Unread triage | Unread count too high to be useful | Marks clearly irrelevant unread mail as read by removing only the UNREAD label | Never deletes, archives or trashes |
| Daily agenda across calendars | Events spread over several calendars | One agenda for today or a requested day from every relevant calendar, sent as one email per theme | Sends only to the user |
| Topic digest | Regular scanning of news on a few topics | Strict last-24-hours digest per topic, with dated source links, drawn from sources in the user's reading languages | No claims without a linked source |
| Weekly status write-up | Same report assembled every week | Collects the week's changes and drafts the report in the user's format | Draft only |
| New-postings pass | Repeatedly checking listings and updating an analysis file | Reads new items, scores them against the user's criteria, and updates the analysis file additively | Never rewrites the file from scratch |
