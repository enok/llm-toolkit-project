# Technical Interview Prep Workflow

Use when a candidate asks for help preparing for, rehearsing, or debriefing one
technical interview. The procedure, modes (full, urgent, debrief only), hard
rules, and report format are in `skills/technical-interview-prep/SKILL.md`; read
its Hard Rules first and follow it. For a multi-week plan across several
interviews use `skills/interview-prep-planner/SKILL.md`. Everything personal (CV,
employers, metrics, the cheat sheet) stays in the candidate's own files, never
in this toolkit.

## Steps that need the person live

1. **Intro rehearsal.** The candidate delivers the intro in the interview
   language, uninterrupted. After each round: what worked, then the numbered
   error list with corrected phrasing; re-check every earlier error each round;
   stop when a round is clean (target 60 seconds, 75-80 accepted).
2. **Full mock interview.** Run
   `skills/technical-interview-prep/references/mock-interview-protocol.md` end
   to end; score only at the end, merge errors into the running list, repeat
   while time allows, and respect a decision to stop.
3. **Tracker update.** If the candidate tracks applications, update the row's
   interview stage with the evidence (`workflows/job-search-pipeline.md`).
