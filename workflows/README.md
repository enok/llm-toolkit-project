# Workflows

Step-by-step instructions for common engineering tasks. **IDE-agnostic** - use via `.windsurf/workflows/` (after setup), Cursor rules (`workflow-*.md` after sync), or direct paths.

## Available workflows

| Workflow | File | Use when |
|----------|------|----------|
| **ticket-review** | `ticket-review.md` | PR, branch, or uncommitted diff |
| **ticket-review-and-fix** | `ticket-review-and-fix.md` | Review + fix + test + push loop |
| **pre-pr-check** | `pre-pr-check.md` | Full review-ready gate before PR |
| **ticket-research** | `ticket-research.md` | Deep ticket research and brief |
| **project-discovery** | `project-discovery.md` | Onboarding and architecture map |
| **research-analysis-cycle** | `research-analysis-cycle.md` | Research or thesis analysis loop |
| **gh-fix-ci** | `gh-fix-ci.md` | Failing GitHub Actions |
| **gh-address-comments** | `gh-address-comments.md` | PR review threads |
| **environment-diagnose** | `environment-diagnose.md` | Local env, auth, containers |
| **security-report** | `security-report.md` | OWASP-style parallel audit |
| **security-check-required** | `security-check-required.md` | Mandatory security gate for repo changes |
| **update-docs** | `update-docs.md` | Doc delta after code change |
| **cross-repo-impact** | `cross-repo-impact.md` | Shared contracts across repos |
| **dependency-upgrade** | `dependency-upgrade.md` | Library or runtime upgrades |
| **new-backend-feature** | `new-backend-feature.md` | Backend feature |
| **new-frontend-feature** | `new-frontend-feature.md` | Frontend feature |
| **db-migration** | `db-migration.md` | Database migration |
| **dataset-onboarding** | `dataset-onboarding.md` | New data source or feed |
| **data-pipeline-change** | `data-pipeline-change.md` | Existing Bronze or Silver or Gold change |
| **aws-airflow-terraform-change** | `aws-airflow-terraform-change.md` | Terraform-managed MWAA or Airflow on AWS |
| **notebook-analysis-update** | `notebook-analysis-update.md` | EDA, stats, or notebook change |
| **notebook-to-script** | `notebook-to-script.md` | Promote stable notebook logic into reusable code |
| **notebook-latex-polish** | `notebook-latex-polish.md` | Improve equations and math-heavy notebook prose |
| **ml-experiment** | `ml-experiment.md` | Model or evaluation change |
| **bilingual-doc-sync** | `bilingual-doc-sync.md` | English plus localized docs or notebooks |
| **ticket-implementation** | `ticket-implementation.md` | Implement a ticket from research output |
| **ticket-research-and-implementation** | `ticket-research-and-implementation.md` | Research then implement in one session |
| **ticket-research-and-implementation-and-validation** | `ticket-research-and-implementation-and-validation.md` | Research, implement, then review-and-fix until CI green |
| **document-creation** | `document-creation.md` | Architecture docs, diagrams |
| **run-tests** | `run-tests.md` | Narrowest meaningful tests |
| **pr-automation-review** | `pr-automation-review.md` | Automation or bot PR findings |

Many of these **default to parallel internal lanes** once scope is known; see `rules/multi-agent-orchestration.md`.

## How to invoke

- Natural language matching `INTENTS.md`
- Slash commands where the IDE supports them (for example `/ticket-review`)
- Direct reference: "follow `workflows/gh-fix-ci.md`"

## IDE locations

| IDE | Typical location |
|-----|------------------|
| Windsurf | `.windsurf/workflows/` (symlinked from setup) |
| Cursor | `.cursor/rules/workflow-*.md` (generated by `scripts/sync-tool-configs.sh`; not a separate `workflows/` folder) |
| Claude | Concatenated in `CLAUDE.md` when sync is run |

## Customize

Copy a workflow into your project, then replace commands, paths, and validators with repo-specific values.
